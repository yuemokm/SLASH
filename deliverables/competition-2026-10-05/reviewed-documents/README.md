# 人工核对建议稿

这里的 PRD 与约束对照由本对话助手在实际资料与独立审核结果基础上协助修订，用于继续评审。它们不是最后一次云模型自动修复的结果，也未覆盖应用隔离测试项目中的正式成果。

- `PRD-人工核对建议.md`：恢复完整字段表，将独立四维矩阵放在表后；保留此前模型已修正的地址、名称与导入差异，明确仍待确认的阶段和接口。其余未逐行复核的原字段保留候选标识。
- `约束对照-人工核对建议.md`：分别说明关键来源事实、适用阶段、文档位置、实际原型观察及未决问题；范围仅限本次列明的关键规则。
- `source-manifest.json`：记录原版本、建议稿哈希及人工修订归属；其中源文件名为审核目录名称，与此处便于阅读的文件名不同，文件字节相同。

HTML 的三轮真实模型修订及13项独立交互检查另有完整记录。不能用文档建议稿冒充自动生成通过，亦不能将原型检查解释为真实后台联调或业务负责人已经确认全部规则。
