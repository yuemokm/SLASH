# Slash 参赛材料

本套材料围绕“机会门店新建”的真实原型修改过程，展示资料依据、具体交互验证、修改记录与版本追溯。比赛要求以用户提供的落地价值和差异为准；约三分钟视频是本次选定的讲述长度，不是官方时长要求。

## 文件与使用顺序

1. 先打开最终版 PPTX，讲清任务背景和产品价值；正文和表格可编辑，截图为嵌入图片。
2. 播放 MP4 演示视频：1920×1080、30fps、180秒，中文字幕，无旁白或背景音乐。可以现场讲解，也可以独立看字幕。
3. 用《答辩准备》中的问题练习回答，重点说明与直接使用通用 Agent 的差别及实际验证范围。

## 讲述边界

- HTML 经三轮真实模型局部修订；最终13项独立界面交互检查通过，应用内另有8个场景通过，两组不能相加称为业务覆盖率。
- 原型的定位、编码与服务提交为明确的本地模拟，没有接通实际生产后台。
- 文档部分已有模型修订，也出现过结构回归和输出上限。后续人工核对建议稿单独存放，没有冒充应用中新的自动成功任务。
- 视频中的功能样例和交付工程样例都有相应标注，不能把这些片段当作真实业务已全部确认。
- 没有做同条件的竞品或人工工时对照，不使用未经测量的提效百分比，也不声称其他 Agent 无法完成类似操作。

## 包含范围

参赛 ZIP 只包含最终 PPTX、MP4、答辩稿和本说明。不包含应用配置、模型凭据、测试 profile、数据库、内部原件或完整视频工程。应用安装包、详细测试记录及人工建议稿另外保存在项目交付目录，便于本地复核。

PPT 已通过文件和渲染检查，比赛前仍请在实际演示电脑的 PowerPoint/WPS 中打开一次，确认字体、缩放和视频播放器。此提示是现场准备建议，不代表已在你的演示环境完成验证。
