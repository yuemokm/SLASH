## 1. 模块定位与目标

### 1.1 定位
机会门店是门店**生命周期五阶段**（空白 → 机会 → 合作中 → 待处理 → 闭店）中的第二阶「机会」阶段对应的临时实体，表示**尚未完成正式终端建档必录字段**、但已被业务员在现场发现的潜在合作门店。本模块提供业务员在 SFA 中新建一条机会门店档案并提报提交的能力。

> 阶段依据：《门店运营管理制度-V4.docx》——「机会门店=未完成正式建档必录字段」；生命周期五阶段来自同一文档。

### 1.2 目标
- 让业务员在到店后快速建立机会门店档案（先到先得，抢占唯一建档）。
- 通过必填字段 + 系统/AI 校验去重与真实性核验，防止重复建档。
- 为后续「机会门店转正式终端」流程沉淀基础字段。

### 1.3 非目标（本受限范围不覆盖，标为待确认）
- 机会门店的查询列表、编辑、删除、批量导入、转为正式终端的完整交互界面。
- 后台管理 / MDM / 主动入驻的完整提报链路。

## 3. 业务流程

### 3.1 新增机会门店流程（SFA）
依据《新增终端流程v2.0.docx》：

1. **入口**：SFA 收 POI 推送，或到店后在门店页面选择「新建」，或后台导入（仅上线初期批量导入，后续只能 SFA 手动录入，见《门店运营管理制度-V4.docx》）。
2. 点击「新增机会门店」，进入新建表单。
3. 填写必填字段（网点名称、定位地址等，详见第 4 节）。
4. 选填画像信息、图商信息、联系人信息、配送信息（配送信息仅在合作状态=合作中时必填）、门头照/售卖环境照。
5. 提交 → 系统 + AI 校验：**唯一性**（按定位地址/网点名称/门头照/联系人电话，单或多字段）与**真实性、准确性**校验。
6. 校验通过：生成唯一机会门店编码 `{JHWD}{10位顺序码}`，状态为「未转化」；校验重复：提示已存在建档，遵循**先到先得**。

### 3.2 机会门店转正式终端流程（关联展示）
依据《新增终端流程v2.0.docx》：
1. 在机会门店卡片选择「转化」。
2. 补全正式终端必录字段。
3. 正式外勤访销 → 离店打卡 → 上传 MDM。
> 本受限范围仅展示「机会门店→正式终端」的关联入口与状态变化，转化落地界面归后续需求（待确认）。原型中用「已转化/未转化」状态与提示演示该关联。

## 5. 核心规则

1. **唯一性**：一个机会门店对应一家实体门店，坚决禁止重复建档（03-D2）。系统 + AI 按定位地址/网点名称/门头照/联系人电话，单或多字段校验唯一性、真实性、准确性（《门店运营管理制度-V4.docx》）。
2. **先到先得**：同一门店被多人并发提报时，先提交成功的建档独占（《门店运营管理制度-V4.docx》）。
3. **录入方式**：仅上线初期批量导入，后续只能在 SFA 手动录入（《门店运营管理制度-V4.docx》）。
4. **提交人范围**：自有人员、经销商人员（不含导购）（《门店运营管理制度-V4.docx》）。
5. **网店编码自动生成**，前端不展示、不可改（03-D2）。
6. **网点名称**：新建档时前端展示且必填，但**不允许前端发起变更修改**（03-D3 P=否）；个体/连锁命名规范见 4.1。
7. **配置赠送**：机会门店「可拜访=是、可申请费用=否」（《门店运营管理制度-V4.docx》），作为建档默认口径。

## 6. 异常与边界

| 场景 | 处理 |
| --- | --- |
| 定位失败/无 GPS | 提示重新定位；经度/纬度/定位地址**首次采集不可手工调整**，须重新定位获取（来源 F5/F6/F7「不允许调整」）；详细地址可手动调整。「允许前端发起变更」（P 列=是）为后续许可，不在本首次采集范围，**待确认**；手动地址/重定位是否重跑唯一校验仍**待确认** |
| 联系人电话格式错误 | 前端即时校验并提示（手机 11 位 / 座机区号-号码规则） |
| 提交触发重复建档 | AI/系统校验返回已存在机会门店，展示既有档信息，遵循先到先得，阻止重复 |
| 合作状态=合作中但未填配送方式 | 提交时阻止，提示补全配送信息（03-D62） |
| 图片非现场/缺水印 | 门头照规则要求实时拍摄+水印；前端提示（最终以服务端校验为准，**待确认**） |
| 并发抢占失败 | 提示「该门店已被他人抢先建档」，不覆盖已有档 |

## 8. 验收口径

- 必填字段（网点名称、定位地址、数据来源、经纬度）缺失时阻止提交并提示。
- 定位按钮返回的全角括号地址（如「…天府三街288号（104.059175,30.547244）」）可直接通过本地校验并提交；首次定位地址只读、不可手工编辑，详细地址可编辑。
- 联系人电话满足 11 位手机或座机 `区号-号码` 格式；否则提示。
- 网点名称/定位地址参与唯一去重提示；重复时遵循先到先得。
- 配送方式选择后联动所属配送商范围提示；合作状态=合作中时配送方式必填。
- 提交成功生成机会门店编码 `{JHWD}{10位顺序码}`，状态=未转化。
- 演示数据与后端模拟在原型中清晰标注（见 `QE12/index.html` 顶部声明与各控件注释）。
