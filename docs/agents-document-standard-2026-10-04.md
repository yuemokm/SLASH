# 统一 AGENTS.md 项目上下文

日期：2026-10-04。版本：0.3.5，已完成。最新要求覆盖此前单数 agent.md 的命名。

## 通用约定

统一使用项目根目录的 **AGENTS.md**，大写、复数。这是跨工具的项目上下文与工作指引约定，并非所有智能体都强制生成的文件。规范使用普通 Markdown，没有必填字段：[AGENTS.md 官方说明](https://agents.md/)。本项目安装的 Pi SDK README 也列出 AGENTS.md / CLAUDE.md 的自动上下文发现。

新项目只自动生成这一份上下文文件，继续使用 skills、模板、参考资料三分类空目录，不恢复任何示例或旧默认业务规则。

## 单文件职责

- 人工区域：项目说明和手写规则，保留用户内容。
- 自动区域：既有 `slash:resource-index` 起止标记间的目录与资料索引，由 Slash 更新。
- 任务前同步并读取，人工规则与资料索引分别传入运行时，索引只注入一次。
- 修改人工规则时保留当时最新自动索引；资料更新时保留人工区域。
- 整份文件上限 128 KiB，人工区域上限 64,000 字节。自动索引预留完整人工规则预算；目录过多时明确标记截断，剩余资料仍可按需查询。

## 旧项目兼容

只有旧 agent.md 时迁移到 AGENTS.md；两者同时存在时保留已有人工规则，合并旧文件人工区域并重建一个自动索引区域。旧文件内容确认已保存且未变化后才移除旧路径。迁移记录支持中断恢复和幂等，不能重复追加同一份人工内容。

遇到损坏标记、路径链接、内容超限或并发编辑时保留原文件并说明错误，不覆盖用户规则。Windows 上已有小写复数 agents.md 需要按实际文件识别，不创建大小写重复的规则文件。

旧运行记录仍保留当时实际读取的单数路径。新记录使用 AGENTS.md；旧规则草稿按原全文哈希保守处理冲突，新草稿可只绑定人工内容，避免资料自动索引变化误覆盖规则。
