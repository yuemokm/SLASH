## 对设计 brief 的补充检查项

现有 brief 已覆盖主要方向，以下验收细节建议纳入最终执行记录：

1. 权限的真实选中态及保存值一致性，尤其泛化 CSS 覆盖后的三主题效果。
2. 设置模型/连接子表单的长内容、错误和高级字段状态，固定动作区与旧偏移清理。
3. 文件页必须包含目录进入后的列表和搜索状态，不能以两张目录卡片或空态代替完整验收。
4. 质量检查长报告、差异、历史的可读层级，以及动作菜单切换内容后自动关闭。
5. 窄预览工作空间比例和导航收起/恢复策略；仅“无全局横溢”不充分。
6. 统一 SVG、复选框及滚动条覆盖设置、列表、报告、弹层，不限会话空态。
