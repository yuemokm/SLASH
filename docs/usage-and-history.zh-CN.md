# slash

面向 B 端产品经理的本地桌面 Agent。以会话为编辑入口，使用已授权目录中的调研、规范和历史成果，生成与修改 HTML 原型、PRD、流程图等材料。

当前源码版本为 0.3.12，日常查看请双击根目录的 [双击启动开发环境.bat](../双击启动开发环境.bat)。按用户约定，日常修改不自动制作便携版，仅明确要求时打包。项目浏览、共享管理与审批修复见 [本轮记录](project-browsing-sharing-approval-2026-10-05.md)。最新增加 [Pi 增量草稿编辑与原生压缩配置适配](draft-edit-2026-10-05.md)，真实业务修订结果见 [修改闭环记录](pm-revision-loop-2026-10-05.md)。接续 [原型交互验收与版本证据](prototype-acceptance-2026-10-05.md)、[原始资料与提取文本的版本核对](source-freshness-2026-10-05.md)、[Word / Excel 副本提取与证据检索](pm-evidence-foundation-2026-10-05.md) 和 [业务规则与成果落实核对](pm-business-trace-2026-10-05.md)。上下文仍由 Pi 原生管理，模型容量按来源解析并可手动配置，见 [设计和验收记录](pi-native-context-2026-10-05.md)。参考资料只读与处理副本见 [0.3.6 记录](reference-protection-and-run-recovery-2026-10-04.md)；统一 AGENTS.md 见 [0.3.5 记录](agents-document-standard-2026-10-04.md)，资源三分类和空目录初始化见 [0.3.4 记录](resource-layout-2026-10-04.md)，整体界面设计见 [界面交付记录](delivery-ui-design-2026-10-04.md)。

资料读取区分来源正文与仅文件信息；规则追溯收在现有工作问题中，按需展开，不要求普通任务登记全部字段。规则可定位到来源和 PRD / HTML 的内容版本，改版后提示重新核对。版本一致不代表业务正确。上述增量已包含在便携包中；真实资料解析、自动测试、桌面验收和云模型未验证范围见对应记录。

0.3.9 核对已登记处理输出时，同时检查其原始资料和处理时副本；原 Excel 改过而旧文本未变也会提示。未知旧回执和无法读取的阶段不会被当成有效，独立授权文本仍可阅读。需要更新时回到会话创建新副本和草稿，不自动覆盖旧成果。比赛业务场景与待验证部分见 [演示与验收准备](competition-readiness.md)。

0.3.10 在 HTML 预览中提供可折叠的“原型验收”：回会话准备场景，在 Build 下执行真实点击和输入，查看预期、实际与截图，失败可带证据回会话。用户可将已确认的用例设为交付要求；入口、网页依赖或依据变更后须重新核验。必检 ZIP 只包含验收过的网页快照，非网页附件须另行交付。该门禁覆盖绑定源文件的文档交付与 HTML/ZIP 导出，暂不覆盖无源文件绑定的通用 MCP 发布。通过页面检查也不代表后台服务或业务规则已经确认。

0.3.11 的 `read_draft` / `edit_draft` 复用 Pi 的文本编辑器，局部修改保留待应用草稿与原始版本校验。小窗口模型未显式配置近期保留量时，采用 session 内的原生模型配置；不改模型容量、不另写压缩算法。291 项测试、构建与便携启动检查已通过，不能由此推定每次云模型修订都成功。

0.3.12 将全局资源和成果组织为项目目录，skills 按包逐层浏览；跨项目预览保持当前会话，引用时明确进入所属项目。共享页增加停止共享、修改显式授权、断开映射和更新连接凭据。完全访问的新任务不再显示已结束的历史审批，迟到或重复授权不会重新执行或扩大权限。实现与验证见 [项目浏览、共享管理与审批修复](project-browsing-sharing-approval-2026-10-05.md)；共享命令与界面已做隔离测试，真实双机 SMB 尚未验收。

## 本地开发

环境：Windows，Node.js 24，npm。实际依赖版本由 package-lock.json 锁定。

```powershell
npm ci
npm run check
npm test
npm run start
```

开发时使用 `npm run dev`：脚本先编译 Electron 主进程和 preload，然后在 `http://127.0.0.1:5173` 启动 Vite，并让 Electron 窗口加载这个地址。渲染进程改动会通过 Vite HMR 更新；主进程或 preload 改动需要重新启动 `npm run dev`。按 Ctrl+C 会同时停止 Electron 和 Vite。PowerShell 中可用 `$env:PM_SLASH_DEV_PORT='5174'; npm run dev` 更换端口。

`npm run dev:renderer` 只启动 Vite 渲染服务器，适合检查静态界面；它没有 Electron preload 和 IPC，浏览器页面不能代表完整应用。`npm run build` 生成生产渲染包和 Electron 主进程，`npm run start` 会先执行该构建，再让 Electron 从本地文件启动，不使用开发服务器。

## 打包

```powershell
npm run pack
```

产物位于 release：便携版 EXE 与 win-unpacked 目录。便携版会解包后启动，首次启动可能稍慢。包不携带模型密钥、工作空间或个人 CLI 登录状态。

## 首次使用

1. 设置中选择工作空间，新项目创建资源、成果和过程文件三个顶层目录。资源只包含 skills、模板、参考资料，模板下保留四种空分类；成果按原型、PRD、流程图等分子目录。只建立目录和统一的 AGENTS.md 项目上下文，不生成示例文件。可在设置的项目结构树中调整。
2. 设置模型 API 地址、精确模型 ID 和密钥，测试连接。密钥经系统加密后保存在本机应用配置。
3. 把调研资料放入资源下的参考资料目录，也可添加其他授权目录；资源页签对应真实子目录，导入文件会进入当前所选目录。
4. 在会话描述任务；Agent 先查资料，再生成草稿。查看草稿并应用，成果保存到相应目录。
5. 从资源或成果打开预览，将文件或选中元素带回会话进行修改。

参考资料原件只读，转换前通过右键“创建处理副本”或 Agent 工具复制，默认放入过程文件/处理副本并添加后缀，结果另存草稿。当前提供内置文本提取和隔离 JavaScript；项目含参考原件时，不允许任意宿主 Python/PowerShell 执行绕过文件保护。上下文计算、压缩与有界自动恢复由 Pi 原生负责，Slash 不再提前估算拦截或追加另一轮压缩；未恢复的截断回复保留部分内容并提供继续入口。本次不自动重放历史任务。更新后须退出旧进程并重启，不能只刷新页面。

设置 → 模型 → 编辑模型 → 高级：模型容量，可以查看上下文窗口、最大输出及每项来源。明确手动值优先，其次使用当前端点声明的能力和精确匹配的 Pi 目录；未知模型显示未验证兼容值，不能把它当作供应商真实容量。“恢复自动值”后须保存。无密钥可查看本地目录能力，实际调用模型仍须配置密钥。

会话输入区的“+”菜单提供引用资料、添加图片和原型、PRD、资料研究、会议整理等快捷动作。提示词加入输入区后可以直接修改，任务上下文可以移除；会议整理和原型补 PRD 需要选取真实来源，变更说明从成果版本差异发起。运行卡保留资料路径、内容哈希、版本与截断信息，便于核对输入。

模型菜单按供应商分组，在能力已确认时提供思考强度滑块。档位来自 Pi 已适配目录或上游明确的模型元数据；未知能力不猜测，仍可正常聊天。已验证能力保存在本机，按需重新检测。项目右键支持重命名、置顶、打开文件夹、复制路径及删除；删除仅移除应用登记，保留本地文件和历史，重新加入原目录可恢复。

模式与权限使用独立菜单：Build / Plan，以及标准权限 / 自动接受 / 完全访问。助手回复末尾可复制完整 Markdown，并显示实际完成时间和生成耗时。系统提示词在设置中修改，保存后从下一次任务生效；权限约束仍由宿主执行。

资源变更会同步到项目根目录 `AGENTS.md` 的自动索引区域，每次任务、Plan 确认与恢复前都会同步并读取。人工规则和资料索引共用一个文件，各自更新时保留另一部分。旧 `agent.md` 会在重新打开项目时迁移，遇到已有人工 `AGENTS.md` 时安全合并；详见 [统一 AGENTS.md](agents-document-standard-2026-10-04.md)。树编辑只应用目录配置并增建目录；旧默认结构的升级只清理精确匹配的未编辑内置示例和空目录，保留用户文件与自定义结构。目录说明见 [资源三分类](resource-layout-2026-10-04.md)。

待确认事项和检查问题随当前会话/成果显示，可切换查看项目历史。模板文件从资源页访问，模板规则管理与共享保留在辅助工具中。设置将子任务、模型路由和共享锁参数收在高级区，已有配置不会被重置。完整 PRD 章节是一般建议，模块说明和普通笔记不强制套用整份 PRD；静态检查不代替人工验证业务规则和原型交互。

已实测模型：Baishan `https://api.edgefn.net/v1` 下的 `DeepSeek-V4-Flash-0731`。对 DeepSeek 使用显式关闭思考参数完成基础工具测试；不保证其他兼容网关支持完全相同的参数。

## 外部工具

- 飞书/钉钉：安装并登录对应官方 CLI，连接管理中填写可执行程序路径。Windows 应优先选择 `.exe`，避免命令行脚本的转义差异。
- MCP：配置 stdio 命令与参数或 HTTP 服务地址，先检查工具能力；发布所需参数取决于服务自身协议。
- 网络盘：使用 Windows SMB。接收者可选择当前 Windows 身份，或输入共享方认可的 `计算机名\用户名` / `域\用户名` 和密码。密码只用于当次隐藏的 PowerShell 映射进程，通过 stdin 传入，应用不会把它写入邀请、命令行、环境、配置、回执或模型上下文，也不会静默尝试 Guest；连接结束后密码框会清空。创建共享需要适当权限，同网段不等于自动授权。

## 当前规范能力边界

- Markdown 模板迁移依赖 `<!-- pm-section:稳定标识 -->`，会保留正文和模板外章节，并在多文件迁移前展示影响和冲突；当前不迁移 Word 样式。
- draw.io 阅读器只安全解析未压缩 XML 子集：矩形、圆角矩形、椭圆、菱形、文本、直线和正交连线。压缩页面、复杂形状、嵌套节点、自环和自定义路由点会显示限制说明，不会伪装成完整预览。
- PDF 支持有文本层的正文读取，不提供扫描图片 OCR；图片不会被当作文本资料解析。
- Word 导出支持常规 Markdown 标题、段落、列表和 pipe 表格；HTML 项目导出是包含相对依赖的源码 ZIP，不代表 React 或其他框架已经执行生产构建。
- 网络盘连接会区分盘符冲突、需要凭据、同主机凭据冲突、目标不可达、离线映射和结果未知。写入超时后先检查盘符状态，不直接重复映射。真实双机连接、普通用户资源管理器可见性、重启恢复和权限撤销仍需现场验收。

在线交付有外部副作用，请核对目标和回执。超时不等于失败，不能直接重复新建。应用连接检查只证明当前检查项，不代表文档发布或双机共享已验收。
