# 全局技能真实材料验证说明

`scripts/global-skills-real-local-smoke.mjs` 使用用户明确指定的本地技能包，在独立测试 profile 与两个独立项目中调用实际 Service、Files 和 AuthorizedSkills，验证安装、发现、技能正文加载、参考文件读取及重启后的持久化。模型传输使用本地测试适配器，没有调用云模型，也没有验证模型遵循技能后的业务成果。

所有原始文件都记录路径、字节数与 SHA-256，并在测试完成后逐份比较；安装使用隔离副本，不修改来源。每项技能的参考文件实际读取最多 3 份，优先覆盖根目录规则、较大知识正文和深层中文路径。报告的 `referenceCoverage` 分别记录可选参考文件总数与实际读取样本数，`references` 仅列出实际读取的文件，不能将样本读取表述为全部参考正文已加载。

2026-10-07，隔离验收记录 `.test-data/global-skills-ui-XjfKOx/real-source/profile/slash.sqlite` 显示技能已发现并加载，资料读取权限为 allow，`read_file` 持续成功。该技能包共有 200 个原始文件，逐份参考文件读取的实测操作间隔约 0.4 秒；每次调用真实网关都会复核全局技能包的文件完整性，逐份加载全部参考正文使脚本超过原有完成预算。此次调整参考文件样本范围，保留全部来源文件前后 hash 核对，不增加等待时间。

后续可研究基于明确授权范围的文件变化监测，减少重复完整 hash 的开销；优化仍须保留技能修改、替换、删除或撤权后的访问拒绝，不能仅用缓存的安装记录证明当前文件仍有效。本轮没有扩大实现范围或变更权限校验。

通俗地说，测试会确认整个技能包没有被改动，并实际打开几份不同类型的参考资料来验证读取路径。它不会声称已把所有参考资料都交给模型阅读。
