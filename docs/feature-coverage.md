## 当前验证边界

运行恢复补充：每个 Run 现在会保存 `RunCheckpoint`，包括阶段、部分回复、已完成工具操作、ContextManifest 引用和 `safeToResume`；应用重启将活动 Run 标记为 `interrupted` 并更新检查点，继续任务会把检查点摘要带入新的 attempt。该机制仍不等同于按工具语义精确续跑，外部操作必须先完成结果核对。

决策追踪补充：决策中心除聚合需求问题、评审问题和结果未知的交付外，还通过独立的 `DecisionRecord` 持久化业务假设、设计取舍、确认事实和交付阻断项。记录包含来源、关联需求/成果、影响、后续动作、确认人和状态历史；确认必须填写确认人，修订冲突会拒绝覆盖。当前 UI 提供手动录入、确认、待核对和否决入口，会话一键沉淀仍可继续增强。
