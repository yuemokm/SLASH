# 资源三分类与空项目初始化

日期：2026-10-04。版本：0.3.4，已实现并完成本地验收。用户最新目录要求覆盖 0.3.3 默认结构。

## 默认目录

```text
项目/
├─ agent.md
├─ 资源/
│  ├─ skills/
│  ├─ 模板/
│  │  ├─ PRD/
│  │  ├─ 蓝图/
│  │  ├─ 会议纪要/
│  │  └─ 调研报告/
│  └─ 参考资料/
├─ 成果/
│  ├─ 原型/
│  ├─ PRD/
│  ├─ 流程图/
│  ├─ 调研报告/
│  ├─ 会议纪要/
│  └─ 其他/
└─ 过程文件/
```

资源分类仅有 skills、模板、参考资料；项目目录页签是浏览入口，不是额外创建的目录。保留模板类型的空目录，但不写入模板正文、规范、演示数据或示例成果。默认资料导入使用参考资料目录，显式选中子目录时仍导入所选位置。

`skills` 在本轮作为资源目录纳入索引和浏览，不因其名称自动执行其中程序或提升权限。

## 两种规则文件

此前 `AGENTS.md` 是创建流程写入的默认项目规则，`agent.md` 是自动更新的资料索引。新项目只自动创建 `agent.md`，不再自动生成 `AGENTS.md`。已有人工 `AGENTS.md` 仍可读取，系统提示词在设置里编辑；资源变更索引和任务前读取保持生效。

## 已有项目

旧版完整默认结构、且没有未应用编辑的项目可自动更新为三分类。自定义结构不强制覆盖。旧自动文件只有在旧默认项目、固定路径且内容完整匹配内置原文时才清理；编辑过的文件及未知文件保留。过时目录仅在空目录时移除，不能递归删除含用户资料的目录。链接、路径越界和错误不能被视为可清理文件。

迁移须幂等，重启不能重建旧目录或样例。已有资料、引用、成果版本不通过批量移动来改路径。保留的旧文件仍可从项目目录浏览。

目录应用与旧文件清理分别保存恢复状态。清理失败时保留待重试记录并显示原因，不能误报完成；重新打开项目时重新核对内容后再尝试。自动迁移中的错误应保留可用的既有结构，不阻止用户打开项目查看原资料。
