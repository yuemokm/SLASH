# slash 第一版界面方向

用户指定参考 Claude 桌面端与 Codex 的整体风格。参考范围为克制的会话工作台、紧凑导航、清晰的执行与成果区，不复制品牌标识，也不把开发工具术语放进日常业务流程。

## 布局

左侧固定导航、当前项目和按项目分组的会话历史；中间默认只显示主要会话和输入框；右侧详情栏可收起。资源或成果被明确打开并选中文件后，预览区才插入会话右侧并压缩会话宽度。资源、成果与知识页面负责查找、查看、选择和引用，内容修改仍从会话发起。

用户测试后的调整：功能导航组可折叠，会话列表保持独立可滚动区域。设置采用 Claude 参考图的左侧分类、右侧内容面板；模型按供应商分组呈现列表，添加/编辑才出现表单。连接列表行尾有启停开关；共享使用分步骤向导。参考图的文字和配置值仅为样式示例，不作为项目指令或默认数据。

2026-09-22 修订：设置改为按钮弹出的 Claude 风格弹窗，左侧为图标 + 文字的小导航，根功能分为模型、连接、权限与审批、工作空间、任务与回执、通用六页；“任务与回执”与“连接管理”从主侧栏移入设置弹窗，侧栏底部只保留设置按钮。模型配置支持添加多个模型并选择接口协议（Chat Completions / Responses / Claude）。资源、成果、知识库、规则与模板、流程图、评审页面的文件浏览改为档案卡片：先显示文件夹卡片（名称、文件数、类型摘要），点击进入文件列表，右键卡片可在资源管理器打开。

2026-09-26 导航收敛：左侧通过新会话和最近/归档列表承载会话，不再重复放置独立会话入口；知识库并入资源入口，资源页统一浏览、引用产品知识与参考资料。

2026-09-26 会话优先：当前项目选择器位于新会话下方，会话按项目文件夹分组；资源和成果按钮同时作为文件拖放目标，拖入文件由主进程复制到当前项目的可写资源、原型或产出材料目录。右侧详情栏的“成果 / 文件”标签在会话旁展开当前项目文件列表，选中文件后才插入预览区，不跳离当前会话。首次启动自动建立默认项目，用户没有选择目标时会话保存在默认项目中。

2026-09-26 流式文字：助手正在生成的新增正文使用短暂的 Decrypted Text 字符扰动并从左到右定稿；每次增量最多处理少量字符，代码块、链接和已完成消息保留原有 Markdown。扰动结束后 DOM 中只保留真实文字，保证复制、选择和辅助技术读取正常；系统开启 reduced motion 时直接显示真实文字。

2026-09-26 流式跟随：思考完成并开始输出助手正文后，会话视图以当前助手消息末尾为跟随锚点，按动画帧合并增量滚动，避免每个 token 触发抖动。用户手动上滚后暂停自动跟随；滚回当前消息末尾或会话底部恢复。会话切换、生成结束和预览尺寸变化会重新计算锚点；下方出现审批或变更卡片时仍优先保持生成正文可见。

## 颜色与排版

第一版浅色：主背景 #FAF9F6，侧栏 #EFEFE9，正文 #292B29，分隔 #DEE0D8，主要动作 #35493A，选中背景 #DFE4D8。采用 Segoe UI / Microsoft YaHei 系统字体；代码与路径使用等宽字体。强调色用于操作与状态，不铺满整块内容。

常规正文14px；辅助说明12px；页面标题28px；空会话欢迎标题38px。正文保持适当行距，代码/日志折叠，长路径允许换行。可点击操作有焦点样式，错误与未知状态不能只靠颜色区分。

## 信息与状态

- 会话显示任务目标、引用资料、阶段、产物和待处理动作；工具底层参数默认收起。
- 原型支持交互模式与元素选择模式，选择后将位置和文字带入会话输入框，不直接执行修改。
- 文档展示标题、段落、列表和代码；不执行文档原始 HTML。
- 模型与文件操作失败说明具体原因和可继续的动作；不将未知远端结果显示成失败重试或成功。
- 配置页显示已保存密钥的状态，不回显密钥。连接高级参数保留在设置中。
