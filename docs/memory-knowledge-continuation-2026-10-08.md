# 长期记忆与知识库续建

2026-10-08。用户要求继续推进前面的模块。此前六项 Pi 包已接入；本轮继续长期记忆、本机知识库和独立问答页面。`billion-context` 明确暂不替换，Pi 原生会话与压缩保持不变。

## 三种内容的职责

| 内容 | 用途 | 真相与边界 |
| --- | --- | --- |
| Pi 原生会话上下文 | 当前任务的历史、压缩和恢复 | 继续由 Pi 管理，不接第二套压缩器 |
| 项目长期记忆 | 下次会话查找候选备忘 | 优先复用 pi-memory；记忆不是已确认业务事实，不得覆盖系统规则或扩大权限 |
| 已确认知识 | 项目认可的业务规则 | 保留 Slash 现有确认、来源及废弃流程，不复制出另一套确认系统 |
| 可分享知识库 | 同事查询明确选择并发布的资料 | 本机索引与云端已发布快照分别记录；网页仅可读取本人有权限的集合 |

## 本轮交付目标

1. 固定版本记忆包经过项目隔离后接入现有受控工具路径。候选备忘绑定来源；写入仍受 Build、权限和取消约束。
2. 补齐本机知识库查询、失败恢复、版本变化检测和发布资料包导出。配置专用向量服务，未配置不得伪造索引成功。
3. 完成独立问答网页、受限 API、资料版本与引用展示、Supabase 授权和数据库迁移，以及本地验证方式。

本轮首先使用合成资料和本机协议服务核验调用及失败行为，不上传真实资料、不自动部署。用户随后提供专用测试服务；根代理查询目录并以两句合成文本核实 `BAAI/bge-m3` 返回 1024 维向量、29 个用量 token。用户要求不改变原任务顺序，故不提前追加真实检索实验。服务密钥未写入代码、文档或测试结果。生产问答质量、真实云授权和部署须另行验收。

## 验收边界

- 记忆跨项目隔离、来源撤权和重启持久化；不影响 Pi 原生压缩。
- 索引只来自所选资料；模型指纹与维度一致；资料变化、权限变化或切换项目不能返回旧正文。
- 问答仅引用本次可访问的已发布资料；撤权后来源链接不可继续读取。
- 浏览器不得获得模型密钥、Supabase 管理密钥、MCP 令牌或本机路径。
- 构建、索引、发布和问答分别显示真实状态；本机通过不能显示已发布。

本轮已完成下述本机开发与验收；真实云端问答和部署仍待后续验证。
