## 2. 产品组织原则

- Workspace 是目录与权限配置的容器，不要求其全部内容位于同一个磁盘路径。
- FolderMount 将本地目录、外部本地目录或 SMB 目录登记为可访问资源；物理文件夹承载原始文件。
- Conversation 是持续工作窗口；一个会话可编辑多个成果，同一个成果可由多个会话处理。
- DesignPackage 改为可选的逻辑成果集合，便于需求关联和交付；不强制用户先创建、不限制检索、不要求迁移文件。可在后台按任务建议建立，用户可改名、合并关联或取消归组。
- Artifact 是注册的成果或可编辑资料，按稳定 ID 与实际路径关联；不同目录中的原型和 PRD 可属于同一逻辑集合。
- 文件浏览、预览、搜索和版本查看不必进入会话；涉及内容修改时，携带选中目标进入当前会话或新会话。设置、认证、文件选择等配置表单可直接操作。
- 系统允许外部编辑器修改文件，但必须检测并处理冲突，不把外部编辑视为应用会话修改。

## 4. 文件夹、权限与资料检索

创建工作空间时预览默认目录：参考资料、资源/文档模板、资源/流程图规范、资源/界面规范、原型、产出材料、过程文件、产品知识库。已有目录优先复用，不覆盖同名内容；用户可更改名称或绑定其他路径。

设置按目录授予 read 或 read_write；拒绝目录和排除子目录优先于父目录授权。新加入的普通参考目录默认只读；通过“连接同事的文件夹”建立的 SMB 协作共享在完成读写校验后作为可写挂载登记。未授权目录不索引、不检索、不读取。路径校验处理 junction、符号链接、大小写和 UNC，不能仅做字符串前缀比较。

跨目录检索顺序：显式引用 → 当前任务关联成果与规则 → 已授权资料中关键词/元数据检索 → 必要时扩大到其他已授权目录。排序结合任务相关性、业务领域、确认状态、版本与更新时间；新资料不自动优先于已确认规则。

读取来源以引用卡片呈现；找不到证据时标记假设或提出问题。检索无结果、资料过期、存在矛盾是三个独立状态。不承诺一次检索找全；扫描文档无法可靠识别时保留原件并显示解析限制。

用户可随时缩小本次任务访问范围。运行中撤销目录授权后，后续工具读取立即拒绝，已进入模型请求的内容无法追回，正在执行任务显示范围已改变。

## 6. 核心业务细节默认值

### 模板升级

“标题提一级”默认作用于选中章节及其子章节，保留相对层级；顶级章节不能再提升，显示原因。未指定范围时询问作用范围。改模板只生成新模板版本；会话展示可更新的关联成果，用户可全选或部分选择。已修改正文保留；章节删除进入变更预览，不无声丢弃。模板结构、Word 样式和生成说明分开保存。

### 编辑与提交

用户明确要求修改指定成果即授权该范围内的普通可恢复编辑：先在草稿中处理，校验成功且无冲突后自动提交快照，显示差异与撤销入口。批量结构迁移、删除、超出原范围的关联修改先展示范围供选择。用户可开启“所有修改均先预览”。所有路径仍经过 ChangeSet，不直接覆盖正式文件。

取消不撤销已完成提交或远端发布；恢复历史创建新版本。两会话修改同一成果时以 Artifact ID/实际资源为锁粒度串行提交，读取基准变更则生成冲突，禁止用“后写覆盖前写”。一个变更涉及多个成果时按固定顺序获取资源锁。

### 原型与 PRD 关联

每个页面、主要业务规则和 PRD 章节维护稳定关联标识。导入旧项目先建立文件和页面索引，缺失关联标记为未建立，模型建议关联需保留置信状态。修改审批规则时扫描原型、PRD、流程和验收；区分确定影响和候选影响。不同步某项成果时保留“与规则版本不一致”状态。

### 调研、联网与提问

默认先查授权资料。可使用已配置联网工具；缺少工具时说明本次仅基于本地资料，不伪造外部调研。只有目标不明、规则冲突或必要输入缺失时提问，每次合并少量关键问题；一般布局和文案由 Agent 给默认方案。模型切换或预算耗尽保留任务状态。

### 交付

一次会话可选择多个交付目标，各自跟踪状态；其中一个失败不重做已成功目标。在线更新要绑定既有 remoteId，不按同名猜测覆盖。飞书/钉钉与 Word 转换可能丢失样式，生成转换报告。发布授权与目标、版本、可见范围关联；未明确目标或公开范围时才补充确认。Agent 与手动在线交付都先形成待审批提案；外部连接只在批准、权限复核与质量门禁通过后执行，手动操作同样保留状态和回执。

### 第一阶段运行可见性（2026-09-26）

每次发送创建一个独立 Run，并持久化 `status`、`phase`、`plan`、`attempt`、`updatedAt`、`finishedAt` 和恢复标记。界面显示任务计划、当前阶段、最近更新时间和错误；审批等待显示为 `waiting_user`，应用重启将未结束运行标记为 `interrupted`，不自动重放工具或外部操作。可恢复运行会从同一会话创建新尝试并保留来源 Run；存在 `outcome_unknown` 外部操作时必须先核对结果。计划卡用于执行摘要和验收提示，不扩大权限范围。

2026-10-06 恢复细化：原 Run 必须失败/中断且完全退出；新尝试在执行前建立明确恢复关系，才能承接同会话安全祖先链的 pending 草稿。成功增量修改后保留原卡与来源历史，正式文件基线、草稿 ID/hash 和资源锁检查持续生效。宿主只注入受限定位元数据，模型仍需重新读取草稿。会话输入严格为“继续”或“继续任务”且无附件/工作流时，只在最新可恢复 Run 的模式、权限、模型和显式思考一致时转官方恢复；其他文字保持普通发送。取消不可恢复，Plan 不升权。详情与验收见 [任务恢复与草稿承接](draft-resumption-2026-10-06.md)。

2026-10-07 复杂任务预算：每次尝试默认最多运行 30 分钟、调用 120 次工具，由集中宿主策略约束。超限保留草稿和准确原因，不无限续期、不自动重放；Pi 网络空闲、重试和未知结果核对保护保持生效。草稿 offset/limit 以 UTF-16 字符计数，默认读取 8000 字符并按 nextOffset 分页。证据和边界见 [有界宿主预算](runtime-limits-2026-10-07.md)。

2026-10-07 草稿状态细化：运行中仍可应用当前 pending。read_draft 准确区分 pending 与 applied 正式文件，无 pending 时不返回 changeId；模型应省略已应用的旧 ID，使用重新读取的最新 hash 创建新卡。旧 ID 不再笼统称内容变化，返回 DRAFT_ID_STALE；版本冲突保护持续生效。普通应用通过现有 operations 保存入口来源、hash、基线和状态，来源不作授权依据。见 [应用后的继续编辑](draft-source-state-2026-10-07.md)。

2026-10-07 输出上限恢复：明确继续 model_output_limit 时保留完整目标和检查点，宿主反馈要求先提交完整小范围工具调用、等待回执后逐块推进，未完成工具参数不得视为已执行；普通失败恢复不注入该反馈。错误按当次限额来源区分宿主未知兼容值与用户/已验证声明，提示在模型设置核对，数值不自动增加。详见 [输出上限的可操作恢复](runtime-output-limit-2026-10-07.md)。

## 7. 页面状态与操作回馈

### Plan / Build 模式与权限模式（2026-09-26）

会话输入框提供独立的 Agent 模式和权限模式选择。Plan 默认使用研究型只读工具读取授权资料、知识库和网页，禁止写入、执行、连接配置和外部发布；方案卡显示模型实际生成的可选方向，选项下方提供可编辑补充区。确认后以完整批准文本创建 Build Run，并持久化来源、选择、自定义内容和精确输入；重复确认不得创建第二个 Build Run。

权限模式分别是标准（遵循每项能力的设置）、接受编辑（自动允许成果编辑）和完全访问（自动允许未禁止能力，并可通过会话电脑scope访问项目外明确目录）。明确禁止优先级最高；完全访问不提升操作系统身份，也不提供操作系统沙箱。标准/接受编辑的目录授权、各模式的显式禁止/只读/参考原件保护、路径检查、版本冲突、结果未知和外部操作核对持续生效。

每个异步区域实现空、加载、成功、错误四种基础状态；长任务另含等待用户、取消中、已中断和结果待核对。失败提示包括发生了什么、哪些产物已保留、下一步动作。不得显示“发布成功”但没有回执或将模拟返回伪装成实际集成。

文件浏览器提供加入会话、预览、定位原文件、查看来源；内容重命名、批量移动和删除默认转为带目标的会话操作卡。误删采用可恢复策略，并明确原始共享文件不能由本机回收站保证恢复。

## 8. 贯穿验收样例

使用虚构“企业客户准入审批”案例：调研放参考资料目录；角色/字段规范放资源目录；HTML 放原型目录；PRD 放产出材料目录。销售提交申请，主管审批，重复信用代码阻止提交，退回需填写原因。

生成后提出“高风险客户增加风控复核；普通客户仍走主管审批”。Agent 必须跨目录读取证据，识别原型、PRD、流程和验收影响，在授权范围完成关联修改。评审后交付 Word、HTML 包和发布链接；飞书、钉钉分别测试创建与更新。用第二台电脑映射读写共享盘，验证它能成为会话参考，也能从资源管理器和 Slash 修改授权文件。

细化技术契约和开发验收见 [开发交付规范](development-handoff.md)。
