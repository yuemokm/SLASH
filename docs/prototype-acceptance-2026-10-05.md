# 原型验收：设计与验收记录

状态：已随 0.3.10 交付，2026-10-05；统一构建、273 项自动回归、14 组执行器检查、开发及打包版各 12 项桌面检查与便携启动均通过。本功能延续现有 Pi、工具网关、成果预览、QualityReport 与工作空间存储，不另建 Agent harness。真实业务原型仍有已明确记录的失败项，不能将工程测试通过解释为业务全部验收通过。

## 要解决的问题

真实模型生成的机会门店原型通过了多项输入与提交检查，但没有服务失败路径。HTML 静态结构检查无法验证点击后的行为。PM 需要能看到“哪个场景试过、预期是什么、实际发生什么、对应哪个版本”，并把失败证据带回会话修改。

入口放在 HTML 成果预览的折叠区域“原型验收”。没有用例时，用户点击准备验收，将可编辑的任务说明带回会话。Agent 根据已读取的需求定义候选用例，用户无需输入 CSS 选择器或 JSON。普通 HTML 不强制创建用例或登记成果身份。

## 运行边界

- Pi 继续负责模型上下文、摘要和压缩；Slash 只处理业务证据、目录权限、浏览器执行及版本状态。
- 用例由有限操作和断言组成。允许点击、填写、选择、指定按键，以及可见性、文本、值、只读、勾选、可用性、数量和相对地址断言。每个用例至少包含一个断言。
- 模型不能提交通过状态、截图或可信文件哈希，不能通过验收工具执行任意 JavaScript、CDP、Shell 或外部请求。
- Build 才能定义及执行；Plan 可读取既有定义和结果。继续使用工具网关及父任务的模式、权限和取消信号。
- 宿主读取已授权目录并构建内存快照，在独立的临时 Electron 会话中加载。浏览器无 Node、预加载脚本或应用 IPC，禁止外部网络、下载、弹窗和越界导航。
- 每个用例使用新的浏览器会话。输入通过宿主固定的原生事件实现，保留 maxlength 和 readonly 等实际行为；断言在隔离世界执行，页面不能自报通过。
- 最多 10 个用例，每个 20 步，总共 100 步，单次执行 60 秒；资源快照最多 100 个文件、16 MiB。超限返回明确结果，不静默丢弃资源后继续报通过。
- 运行错误、资源受阻、崩溃、超时或取消记录为结果未知；确实观察到与期望矛盾的行为才记录失败。未执行的步骤保留未执行状态。

## 版本、依据和交付

用例定义绑定入口文件、规格修订号和规格哈希；执行报告绑定入口及相对资源清单的哈希，以及已授权读取的来源依据。HTML 不变而 JS、CSS 或依据变化时，历史报告也不能作为当前版本的通过证据。

报告保存到既有 QualityReport 仓库。历史执行结果不可修改；另行计算当前、过期或无法核对状态。撤销资料授权后，不继续展示相关原文和截图。执行前、完成时和查看证据时均重新核对授权和版本。

这里的依据哈希核对直接引用的文本文件。若引用 Office 提取文本，它不能单独证明原始 Office 文件仍是最新版本；原件、副本与提取结果的关系由既有来源链核验展示。本轮不把两个状态混为一谈，也不另建 Office 解析链。

默认只提供检查建议。用户可把当前用例范围设为交付必需条件，并确认具体规格哈希。Agent 随后修改或减少用例会使确认失效，不能通过削弱检查绕过交付条件。用户需要明确确认新的验收范围，或自行关闭该要求。既有质量门禁启用时，必需验收的失败、未知、未执行、过期或待重新确认均阻止交付；交付过程本身不隐式启动浏览器。

报告只证明当前版本的具体页面断言表现，不能自动确认业务规则、后台服务或真实数据正确。依据摘录与页面实现一致，也不等于业务假设已获用户确认。

本轮交付门禁的集成范围为已绑定源文件的官方文档交付与 HTML/ZIP 导出。无源文件绑定的通用 MCP 调用无法据此识别要发布的成果，不能宣称已经覆盖所有外部发布渠道。后续若统一发布入口，应复用同一检查及版本回执，而不是从 MCP 返回文字猜测发布内容。

必检开启时，HTML 导出采用已核对的入口字节，ZIP 采用已核对的网页快照及资源，并在最终提交前再次复核。ZIP 不包含同目录 PRD、说明等非网页附件，返回实际文件清单，并在导出结果提示中说明。普通未设必检的 ZIP 保留原来打包目录的行为。只导出 HTML 入口时，相对依赖仍需随项目交付。

## 恢复与生命周期

执行开始先持久化运行状态。应用重启后，未完成执行标为结果未知，不自动重放。取消任务、切换工作空间、撤销授权或关闭应用时，应中断执行并销毁隐藏浏览器窗口。共享源文件始终只读，浏览器从不可变快照运行。

## 需求与验收

| ID | 行为 | 验证要求 |
| --- | --- | --- |
| PA01 | 无成果登记的 HTML 也能定义、运行、查看验收 | Service 集成与实际桌面入口 |
| PA02 | 真实输入保留长度、只读限制，点击触发可信输入事件 | 实际 Electron 探针及运行测试 |
| PA03 | 页面不能联网、越界读取或提交可信通过结果 | 浏览器隔离、安全测试 |
| PA04 | 入口、依赖、规格和依据变更使证据失效 | 确定性哈希及权限测试 |
| PA05 | 用户必需条件绑定已确认规格，Agent 不能削弱后直接发布 | 门禁测试 |
| PA06 | 取消、重启和窗口关闭得到明确状态，无残留窗口 | 生命周期测试 |
| PA07 | 预览内展示期望、实际、截图，失败可带回会话 | 实际桌面冒烟与截图 |
| PA08 | 真实生成原型的缺失路径诚实报失败 | 使用真实模型产出，不手改页面来迎合检查 |

### 使用入口

1. 打开成果中的 HTML 预览，展开“原型验收”。
2. 点击“在会话中准备验收”，说明需要核对的业务场景和依据。提示只加入输入框，不自动发送。
3. 在 Build 下让 Agent 定义用例，查看预期后运行验收；Plan 只能阅读已有记录。
4. 失败项可查看实际结果及宿主截图，再点击“带证据回会话修正”。修改成果后重新执行，不沿用旧版本通过状态。
5. 需要交付约束时由用户勾选“作为交付要求”。用例范围变化后，用户明确确认新范围才能解除范围失效状态。
