# HTML 内容审查的原文选段

已实现。此逻辑改善提供给独立审稿模型的材料，不执行页面、不生成摘要，不判定业务通过。

当成果或来源的 `path/locator` 明确以 `.html/.htm` 结尾且不能全文放入原配额时，宿主在原 HTML 内选取有界的脚本、控件周围正文和相关样式。其它格式仍用既有选段算法。外层文档分配、正文总预算、二遍余量利用、单份字符上限和最终 JSON prompt 限额保留；HTML 未用完配额时，后续文档可按既有规则自然利用余量，不保证一般场景中所有非 HTML 配额恒定。

宿主用保长注释 mask 定位，回传始终是原文 `slice(start,end)`。`start/end` 是 UTF16 code-unit 偏移，正文哈希按 UTF8 计算；行号仍由原文计算。既有引用验证只接受实际已提供片段中的精确原句，不能引用遗漏部分或规范化 DOM。

选段按用户要求的有界英文词/中文双字片段排序，避免被审 HTML 自己全文的自匹配。若完整 inline script 不超过原配额的 75% 且最多 4 段，优先保留；否则选择与要求相关的事件形态/代码段，长单行优先截到绑定附近。控件窗口最多 2 个区间，相关 CSS 先选装得下的完整规则；CSS 固定预留约九分之一额度，使用控件窗口的真实 class 关联，优先较专有的 class 和可读性声明。最多 8 个合并区间，总字符不超过原文档配额。

区域定位不是完整 HTML/CSS parser。先数至第 101 个 script/style 起始标签即退回有界原文前缀，记录结构超限；未闭合结构、外部脚本也记录明确限制。不会执行代码、下载外部 URL、改变读取权限或自动给业务结论。未知限制进入 prompt 和回执，按 `(kind,id)` 精确投影至 wire v2 的 canonical ref。短 HTML 的正文可以为 full，但外部脚本/未闭合结构仍有相应限制，不能宣称页面已经完整运行。

片段改变会改变 inputHash/promptHash。旧冻结输入、旧回执保持历史原样；不能把旧 review 绑定到新选段。无新选段限制的历史输入仍沿原提示渲染，历史调用方自带同前缀限制不重复加入。

离线 D 对比保存在 `.test-data/content-review-html-selection-candidate`：HTML 仍 4216/14123 字符、正文仍 25600 字符，prompt 由 32204 变 32644，仍小于 59392。完整事件绑定形态从 0/4 变为 4/4，3124 字符 inline script 全部可见，名称控件与相关颜色/图标 CSS 可见。完整控件标签只有 2/30，因此仍 partial。所有请求与非 HTML 上下文在该实例逐字段相同，不能推广成所有页面都能完整覆盖。

正式测试采用独立合成 HTML/Markdown 和冻结合成输入；不依赖私有历史 D 文件。它们核对预算、原文引用、旧验签、短 PRD 保留、注释/外部/未闭合/长单行/UTF16/结构上限等边界。真实模型是否发现问题、浏览器交互是否通过，仍须分别验证。

正式集成构建与类型检查通过，35项定向通过；全量有界并发633/633通过，0失败、0取消、0跳过（`.test-data/content-review-html-selection-full-tests-bounded.tap`）。初次全量的单个原生测试进程退出及单组11/11复核记录保留。随后真实QE12因原30分钟预算结束，仅两份Markdown草稿、无HTML，未进入独立内容审查；因此本次没有新增模型审稿收益或页面视觉通过的证据，详见真实资料后续验收。

通俗解释：审稿模型以前可能把有限篇幅都用来读颜色和间距。现在会在同样篇幅里优先加入按钮和表单怎样工作的代码，给审查提供更多有用依据；没有读到的字段仍然明确标为未完整检查。
